# Jinbo Lv — Personal Homepage

Source code for my academic homepage: [jinbolv.github.io](https://jinbolv.github.io).

The site is built with Jekyll and hosted on GitHub Pages. It includes sections for my profile, news, publications, education, internship experience, and contact information.

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000` in a browser.

## Content

Homepage content is organized under `_pages/includes/`. Site-wide identity and social links are configured in `_config.yml`.
